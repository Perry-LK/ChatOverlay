Twitch overlays for OBS

Clean browser sources for chat, alerts, and theme control.

Chat Overlay is a lightweight Twitch overlay toolkit built for OBS browser sources. It gives you an anonymous IRC-powered chat overlay, a matching alerts page, and a customiser that exports a single URL you can drop straight into your scene.

Open chat overlay Open customiser
No login needed Reads Twitch chat anonymously over IRC, so setup stays simple.
Three focused pages Use only the browser source you need: chat, alerts, or theming.
OBS-ready URLs Configuration lives in query parameters or config files, not code edits.

Start in under a minute

  • 1. Run npm install then npm run dev.
  • 2. Open /chat/, /alerts/, or /customise/.
  • 3. Paste the final page URL into an OBS Browser Source.
  • 4. Add ?channel=YourLogin to point the overlay at your channel.

How the project is structured

The root page explains the system. Each actual feature then lives on its own subpage, so OBS only loads the browser source you want to render.

/chat/ Main chat overlay /alerts/ Alert popups /customise/ Theme builder

Typical OBS workflow

  1. Open the customiser if you want to tune fonts, colours, spacing, or visibility.
  2. Copy the generated browser-source URL, or build one manually for chat or alerts.
  3. Add that URL in OBS as a Browser Source sized for your layout.
  4. Keep chat and alerts as separate sources so you can place and animate them independently.

Feature guide

Use the tabs to see what each page does, when to use it, and the URL shape OBS should load.

Chat overlay

The main transparent browser source for Twitch chat. It supports anonymous IRC chat, Twitch badges, 7TV emotes, replies, cheer highlighting, optional fade-out, and URL-driven config.

What it is for Displaying live chat on stream without requiring a Twitch login flow.
What you can tune Theme, fade duration, max messages, badge visibility, replies, bits, command filtering and more.
Where it lives Load the dedicated page at /chat/ as an OBS Browser Source.
Best fit Permanent scene elements like side chat columns, lower thirds, or fullscreen event scenes.
https://you.github.io/ChatOverlay/chat/?channel=PerryLK&theme=comfy

Alerts overlay

A separate browser source for transient Twitch events. It listens for anonymous IRC notices and turns them into pop-up alerts for subs, resubs, gifted subs, sub bombs, cheers, raids, announcements, and bits badges.

What it is for Dedicated alert popups you can position independently from chat in OBS.
What you can tune Alert duration, max queue size, minimum bits threshold, enabled types, and shared theme variables.
What it does not cover Follow alerts are not available here because anonymous IRC does not expose them.
Preview mode Append &test=sub,resub,raid to preview styling without waiting for real events.
https://you.github.io/ChatOverlay/alerts/?channel=PerryLK&test=sub,resub,raid

Customiser

The customiser is the visual editor. It lets you adjust typography, spacing, card styling, visibility, and raw CSS, then exports a single URL containing the final theme64 payload.

What it is for Building a polished chat look without manually editing CSS or config files.
What it outputs A ready-to-paste browser-source URL pointing at /chat/ with your theme choices embedded.
Live preview See sample messages rendered locally while you tweak variables and CSS overrides.
Best fit Creators who want reusable styling presets or per-scene variations without changing source code.
https://you.github.io/ChatOverlay/customise/
