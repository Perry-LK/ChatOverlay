Chat Overlay customiser

Pick a starting theme pack, fine-tune any variable, then copy a single overlay URL with everything baked in.

The configuration is encoded into a ?theme64=… URL parameter. Nothing is uploaded; everything stays in your browser.

Theme packs

Click a pack to apply a curated bundle of variables. You can then tweak individual values below — picking Custom on any field detaches that field from the pack.
